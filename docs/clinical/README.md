# Clinical draft review

These changes are source-mapped drafts, not clinician-approved protocols. No dose was invented. New exercise entries intentionally leave dose selection to the treating clinician. The source-map lists every changed field and its citation.

Not all empty fields can be safely filled. Source stage numbers are not interchangeable with this dataset. Timing windows are mapped only where phase goals match. The source review pack preserves unresolved mismatches and gaps.
